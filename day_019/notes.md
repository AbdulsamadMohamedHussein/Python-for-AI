
# Day 019 – Python List Methods

## Topic
Python List Methods

## What I Learned
Today I learned how to manipulate Python lists using
built-in list methods.

## Methods Covered

| Method | Purpose |
|---|---|
| append() | Adds one element |
| extend() | Adds multiple elements |
| insert() | Inserts at a position |
| remove() | Removes a specified value |
| pop() | Removes an element by index |
| clear() | Empties a list |
| sort() | Sorts elements |
| reverse() | Reverses a list |
| index() | Finds an element's index |
| count() | Counts occurrences |
| copy() | Creates a shallow copy |

## Important Observations

1. append() adds one element.
2. extend() adds multiple elements.
3. remove() uses the element's value.
4. pop() uses an index and returns the removed element.
5. sort() modifies the original list.
6. copy() creates a separate shallow copy.

## Connection to Artificial Intelligence

List methods are useful when:
- Managing datasets.
- Organizing model prediction scores.
- Preparing numerical information.
- Filtering and manipulating data.
- Managing experimental results.
