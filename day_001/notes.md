# Day 1 — Introduction to Python

## 1. What I learned

- Python is a high-level, general-purpose programming language.
- Python is widely used in Artificial Intelligence and Machine Learning.
- Python code is executed by the Python interpreter.
- `print()` displays information on the screen.
- Comments explain code and are ignored during execution.
- Python is case-sensitive.
- Strings are written inside quotation marks.
- Python can perform mathematical calculations.

## 2. Important syntax

```python
# This is a comment

print("Hello, World!")

print(10 + 5)
```

## 3. New terms

| Term | Meaning |
|---|---|
| Python | A programming language |
| Interpreter | Executes Python instructions |
| Function | Reusable code that performs a task |
| String | Text data |
| Syntax | Rules for writing code |
| Comment | Explanation written for programmers |
