# Python for AI — My 90-Day Learning Journey

Welcome to my Python programming learning journey!

This repository documents my 90-day structured journey of learning Python programming with a focus on Artificial Intelligence, Machine Learning and Deep Learning.

I am a Bachelor's student in Artificial Intelligence, and my goal is to develop strong programming foundations and practical skills that will prepare me to work with real-world AI technologies.

This repository contains my daily lessons, practical coding exercises, programming challenges, personal notes and projects.

My philosophy is simple:

**One day at a time. One concept at a time. One project at a time.**

---

## 🎯 Learning Objectives

Throughout this 90-day programme, I aim to:

- Develop strong Python programming fundamentals.
- Improve logical thinking and problem-solving abilities.
- Understand Python data structures and algorithms.
- Learn Object-Oriented Programming.
- Develop practical programming skills through projects.
- Master NumPy for numerical computing.
- Learn Pandas for data manipulation and analysis.
- Use Matplotlib for data visualization.
- Understand PyTorch for Deep Learning.
- Build a foundation for Machine Learning and Computer Vision.
- Develop the ability to implement AI concepts using Python.

## 📚 My 90-Day Learning Roadmap

### Phase 1: Python Fundamentals — Days 1–30

**Goal:** Develop a strong foundation in Python programming.

Topics include:

- Introduction to Python.
- Variables and data types.
- Type conversion.
- Operators.
- Input and output.
- Strings and string methods.
- Conditional statements.
- Loops and loop control.
- Lists, tuples, sets and dictionaries.
- Functions and parameters.
- Modules and imports.
- Exception handling.
- File handling.
- Object-Oriented Programming.
- Basic problem-solving and practical projects.

### Phase 2: NumPy — Days 31–45

**Goal:** Learn numerical computing for Artificial Intelligence.

Topics include:

- Introduction to NumPy.
- Creating NumPy arrays.
- Array dimensions and shapes.
- Array indexing and slicing.
- Array operations.
- Mathematical operations.
- Broadcasting.
- Vectorization.
- Statistical operations.
- Matrix operations.
- Linear algebra fundamentals.
- Numerical data preprocessing.

### Phase 3: Pandas — Days 46–57

**Goal:** Learn how to work with real-world datasets.

Topics include:

- Introduction to Pandas.
- Series and DataFrames.
- Reading CSV files.
- Reading and writing datasets.
- Selecting and filtering data.
- Handling missing values.
- Removing duplicates.
- Data cleaning.
- Grouping and aggregation.
- Merging datasets.
- Data analysis and exploration.

### Phase 4: Matplotlib — Days 58–65

**Goal:** Understand data visualization and graphical analysis.

Topics include:

- Introduction to Matplotlib.
- Line plots.
- Bar charts.
- Scatter plots.
- Histograms.
- Plot customization.
- Labels, titles and legends.
- Visualizing statistical distributions.
- Understanding AI training and performance graphs.

### Phase 5: PyTorch and AI Programming — Days 66–90

**Goal:** Develop a practical foundation in Deep Learning.

Topics include:

- Introduction to PyTorch.
- Understanding tensors.
- Tensor operations.
- Tensor dimensions and shapes.
- Automatic differentiation.
- Computational graphs.
- Neural network fundamentals.
- Building neural networks.
- Activation functions.
- Loss functions.
- Optimization algorithms.
- Backpropagation.
- Model training.
- Training loops.
- Dataset and DataLoader.
- Model evaluation.
- Introduction to Computer Vision.
- Building introductory Deep Learning projects.

## 💻 My Daily Learning Method

Each learning day follows a practical approach:

1. **Main Lesson:** Study the topic and understand its concepts.
2. **Practical Coding:** Write Python code and understand how it works.
3. **Exercises:** Solve programming exercises independently.
4. **Coding Challenge:** Apply the concepts to a practical problem.
5. **Notes:** Document important explanations, commands and examples.

I focus on understanding the code rather than simply copying it.
